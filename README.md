# JavaScript Basics

A beginner-friendly collection of JavaScript concepts, examples, and exercises to help you learn the fundamentals of JavaScript.

## 📚 Topics Covered

* Introduction to JavaScript
* Variables (`var`, `let`, `const`)
* Data Types
* Operators
* Type Conversion
* Conditional Statements (`if`, `else`, `switch`)
* Loops (`for`, `while`, `do...while`)
* Functions
* Arrays
* Objects
* Strings
* DOM Manipulation
* Events
* ES6 Features

  * Arrow Functions
  * Template Literals
  * Destructuring
  * Spread and Rest Operators
  * Modules
* Error Handling
* Asynchronous JavaScript

  * Callbacks
  * Promises
  * `async/await`

## 🛠️ Prerequisites

To get started, you only need:

* A modern web browser
* A code editor such as Visual Studio Code
* Basic understanding of HTML and CSS (optional but recommended)

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/your-username/javascript-basics.git
```

2. Navigate to the project directory:

```bash
cd javascript-basics
```

3. Open the project in your preferred code editor.

4. Run the examples by opening the HTML files in your browser or using a live server extension.
